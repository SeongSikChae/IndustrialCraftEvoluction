## 1. 용어 (검토 반영)

| 용어 | 의미 |
|------|------|
| 축(shaft) | 본체에 이어진 **짧은 원통** + 바깥쪽 끝에 **돌아가는 허브/톱니**. 큰 다크 패널/문이 아님. |
| 출력면 | 동력이 나가는 면 = 축이 있는 면 |
| 입력면 | 동력을 받는 면 |
| look | 설치 시 플레이어 수평 시선 |
| toward player | `look.opposite()` — 설치 직후 플레이어가 마주보는 블록 면 |

---

## 2. 화로 엔진 — 승인된 규칙

| # | 규칙 | 검토 |
|---|------|------|
| E1 | 배치: 축/출력 = **toward player** (`FACING = look.opposite`) | ✅ 승인 |
| E2 | `FACING` = 축 방향 = 출력면 | ✅ (E1에서 파생) |
| E3 | 축 형태: 본체 연결 짧은 원통 + 끝 허브/톱니 | ✅ 승인 |

### 구현 세부 (코드 반영됨 — 변경 시 §5 체크리스트)

- 메시 축 authored `+X`; blockstate CW: east0 / south90 / west180 / north270
- BER: `+X` → `FACING`, 본체·칼라에 붙는 짧은 조립체
- `outputsToward(face)` ⟺ `face == FACING`
- 배기구 등 부속은 authored 기준을 같은 회전표로만 맞춤

### 합격 조건

1. 설치 직후 보이는 면에 짧은 회전 축
2. 반대면은 축이 아님
3. Dynamo는 그 축 면에서만 동력 수신 가능

---

## 3. Dynamo — 승인된 규칙

| # | 규칙 | 검토 |
|---|------|------|
| D1 | 동력원 축을 보고 설치 → **시선 쪽 = 입력**, **등 뒤 = 출력** | ✅ 승인 |
| D2 | 입→출 **1:1** (torque / omega 동일) | ✅ 승인 |
| D3 | I/O 축 양끝 제외 **4면**에 토크·각속도·출력(W) 표시 | ✅ 승인 |
| D4 | 출력 축 메시 = 화로 엔진과 동일 (칼라 + 회전 BER 톱니) | ✅ 승인 |
| D5 | 입력 = 본체 안쪽 오목 베어링(축 삽입 느낌) | ✅ 승인 |

### 구현 세부 (코드 반영됨 — 변경 시 §5 체크리스트)

- `FACING` = 출력, `inputFace = FACING.opposite()`
- 배치: `FACING = look.opposite()` (look이 입력 방향)
- authored: 출력 north(−Z) 칼라, 입력 south(+Z) 오목 베어링; blockstate는 FACING=출력에 맞게 CW
- 출력 BER: 화로와 동일 `furnace_engine_gear`, ω에 비례 회전
- `outputsToward` = 출력면만
- 입력: 이웃이 `outputsToward(inputFace.opposite())`

### 기준 시나리오

1. 남쪽 보고 엔진 설치 → 축 북  
2. 엔진 북쪽에 Dynamo, 엔진을 보고(남쪽) 설치 → 입력 남 / 출력 북  
3. 엔진 가동 시 Dynamo 비-I/O 4면에 동일 수치  
4. 체인도 “앞단 출력축을 보고” 같은 배치

### 합격 조건

1. 축에 입력면을 맞췄을 때만 수치 상승  
2. 표시는 I/O가 아닌 4면만  
3. 출력면 쪽으로만 다음 단 전달
